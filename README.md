## 🩺 Overview

**AI Healthcare Chatbot** is a Python-based healthcare assistance system designed to provide **preliminary health guidance** by analyzing symptoms entered by users through a conversational interface.

The system processes the provided symptoms against a structured **disease knowledge base**, identifies possible health conditions, provides associated precautions and recommendations, and generates a professionally formatted **PDF health report**.

> ⚠️ **Important:** This project is intended for educational and preliminary informational purposes only. It does not replace professional medical diagnosis, treatment, or consultation with a qualified healthcare professional.

## 🚀 Core Features

### 🧠 Intelligent Symptom Analysis

Analyzes symptoms provided by the user and matches them against the disease knowledge base.

### 💬 Conversational Interaction

Provides a simple chatbot-style interface for interacting with the healthcare system.

### 🔬 Disease Prediction

Uses a structured JSON dataset containing diseases, symptoms, precautions, and recommendations.

### 📄 Automated PDF Reports

Generates a formatted health report containing the user's information, symptoms, prediction, and recommendations.

### 🗂️ Modular Architecture

The application is divided into separate modules for chatbot logic, disease data, application handling, and PDF generation.

### ⚡ Lightweight & Extendable

The disease knowledge base can easily be expanded with additional conditions and medical information.

## 🧩 Module Breakdown

### `app.py`

Controls the overall application flow and user interaction.

### `chatbot.py`

Handles conversational interaction and symptom processing.

### `disease_data.json`

Acts as the structured healthcare knowledge base.

Example:

```json
{
    "disease": "Example Condition",
    "symptoms": [
        "fever",
        "headache",
        "fatigue"
    ],
    "precautions": [
        "rest",
        "stay hydrated"
    ]
}
```

### `pdf_generator.py`

Uses **ReportLab** to convert the analysis into a structured PDF health report.

## 🔐 Safety & Responsible AI

Healthcare applications require responsible handling of information.

This project therefore treats its output as **preliminary informational guidance**, rather than medical diagnosis.

### The system should NOT be used to:

* Replace a doctor or healthcare professional
* Confirm a medical diagnosis
* Prescribe medication
* Handle medical emergencies
* Replace professional treatment

### 🚨 Emergency situations

Users experiencing severe, sudden, or life-threatening symptoms should seek immediate professional medical assistance rather than relying on the chatbot.
